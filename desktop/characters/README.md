# 캐릭터

기본 캐릭터는 **엔젤이**(`angel/`)입니다. 그림이 하나도 없으면 `renderer/index.html` 안의 SVG 캐릭터가 대신 나옵니다.

## 표정

| 파일 | 언제 | 엔젤이 |
|---|---|---|
| `idle` | 평소 (꼭 있어야 함) | 기본 |
| `thinking` | 대화·리뷰 중 | 공부/읽기 |
| `warn` | 리뷰 판정 "막힘" | 놀람 |
| `happy` | 리뷰 판정 "머지 가능" | 신남/활짝 |
| `sleep` | 방해 금지 | 졸림 |

확장자는 `.png` `.jpg` `.gif` `.svg` `.webp` 중 하나. 없는 표정은 `idle`로 보입니다.
크기는 240×264(화면 120×132의 2배), 배경 투명, 캐릭터는 아래쪽에 붙입니다. 움직이는 그림은 `.gif`로.

## 엔젤이 다시 뽑기

캐릭터 시트를 고쳤으면 `cut_angel.py`로 다시 자릅니다. 표정 칸 위치는 스크립트 위쪽 `BOXES`에 있습니다 (1536×1024 시트 기준).

```bash
python3 -m venv /tmp/pil && /tmp/pil/bin/pip install pillow==12.0.0
/tmp/pil/bin/python characters/cut_angel.py "<시트.png>" characters/angel
```

## 다른 캐릭터로 바꾸기

메뉴 막대 **사수 → 캐릭터 → 그림 골라서 바꾸기…**

- **한 장**만 고르면 모든 표정에 그 그림을 씁니다. 표정마다 움직임(흔들기·뛰기)은 달라집니다.
- **여러 장**을 고르면 파일 이름으로 표정을 나눕니다: `idle`·`thinking`·`warn`·`happy`·`sleep` 또는 `기본`·`생각`·`놀람`·`신남`·`졸림` (예: `고양이_신남.png`).
- png·jpg·webp는 **배경(누끼)을 자동으로 지우고** 빈 여백을 잘라 냅니다. 가장자리와 이어진 단색 배경만 지우니 캐릭터 안쪽의 흰 눈 같은 건 남습니다. 이미 배경이 투명하거나, 배경이 사진처럼 제각각이면 그대로 둡니다.
- gif·svg는 그대로 씁니다 (움직이는 그림은 gif로).
- 크기 제한: png·jpg·webp는 50MB까지 (화면 크기로 줄여 저장), gif·svg는 5MB까지.
- 고른 그림은 앱 폴더(`~/Library/Application Support/sasu-buddy/character`)에 복사되니 원본을 옮겨도 됩니다. **캐릭터 → 엔젤이 (기본)**으로 언제든 되돌릴 수 있습니다.

직접 다듬은 그림 폴더를 쓰려면 설정 파일의 `characterDir`에 그 폴더 경로를 적고 **설정 다시 읽기**.
